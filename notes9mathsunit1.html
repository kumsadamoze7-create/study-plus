📘 Unit 1 Overview

In this unit, we study sets and the different ways sets can be described and represented. We also learn how to compare sets and perform operations such as union, intersection and complement.

Sets are important because they provide a mathematical way of grouping objects that have a common property. They are also used in probability, statistics, logic, computer science and many other areas of mathematics.

1.1 Sets and Elements

What is a Set?

Definition:
A set is a well-defined collection of distinct objects.

The objects in a set are called elements or members of the set.

Example:

Let A = {2, 4, 6, 8}

Then 2, 4, 6 and 8 are the elements of A.

Membership Symbols

  • ∈ means "is an element of"
  • ∉ means "is not an element of"
For A = {2, 4, 6, 8}:

4 ∈ A ✔️

5 ∉ A ✔️

Important Properties

  • The order of elements does not matter.
  • Repeated elements are counted only once.
  • A set must be well-defined.
⚡ Short Trick:
Remember: Set = Collection + Well-defined + No repetition

1.2 Ways of Describing a Set

There are several common ways to describe a set.

1. Roster / Listing Method

The elements are written inside curly brackets.

A = {1, 2, 3, 4, 5}

2. Descriptive Method

The set is described using words.

A = the set of positive even integers less than 10.

3. Set-Builder Method

A rule or property is used to describe the elements.

A = {x : x is a positive even integer less than 10}

The symbol : can be read as "such that".

⚡ Short Trick:
Roster → list the elements.
Descriptive → describe with words.
Set-builder → give a rule.

1.3 Types of Sets

Finite Set

A set containing a limited number of elements is called a finite set.
A = {1,2,3,4}

Infinite Set

A set that continues without ending is an infinite set.

N = {1,2,3,4,5,...}

Empty Set

A set with no elements is called an empty set or null set.

Symbols: ∅ or { }

Singleton Set

A set containing exactly one element.

A = {7}

Equal Sets

Two sets are equal if they contain exactly the same elements.

A = {1,2,3} B = {3,2,1} Therefore: A = B
⚡ Remember:
Order does NOT matter in a set. {1,2,3} = {3,1,2}

1.4 Subsets

Set A is a subset of set B if every element of A is also an element of B. Symbol: A ⊆ B
Let: A = {1,2} B = {1,2,3,4} Since every element of A is in B: A ⊆ B

Proper Subset

A is a proper subset of B if A is a subset of B but A is not equal to B.

Symbol: A ⊂ B

Important Facts

  • Every set is a subset of itself.
  • The empty set is a subset of every set.
  • A proper subset must be smaller than the original set.
⚡ Short Trick:
To check A ⊆ B: Take every element of A and ask: "Is it inside B?" If all are YES → A ⊆ B.

1.5 Universal Set

The universal set is the set containing all objects under consideration in a particular problem. It is usually represented by U.
Suppose: U = {1,2,3,4,5,6} A = {2,4,6} Then A is a subset of U.

Complement of a Set

The complement of A contains all elements of U that are not in A.

Symbol: A′ or Aᶜ

U = {1,2,3,4,5,6} A = {2,4,6} Therefore: A′ = {1,3,5}
⚡ Short Trick:
Complement means: "Everything in U except A."

1.6 Operations on Sets

Union

The union of A and B contains every element that belongs to A or B or both. Symbol: A ∪ B
A = {1,2,3} B = {3,4,5} A ∪ B = {1,2,3,4,5}

Intersection

The intersection contains elements common to both sets. Symbol: A ∩ B
A = {1,2,3} B = {3,4,5} A ∩ B = {3}

Difference

A − B contains elements that are in A but not in B.

A = {1,2,3} B = {3,4,5} A − B = {1,2}
Union → ∪ → Put everything together.

Intersection → ∩ → Common elements.

Difference → − → Keep the first set's elements that are not in the second.
⚡ Easy Memory Trick:

∪ = OR

∩ = AND

1.7 Venn Diagrams

A Venn diagram represents relationships between sets using circles.

Basic Interpretation

  • Inside a circle → elements belonging to the set.
  • Overlap → intersection.
  • Combined circles → union.
  • Outside the circle but inside U → complement.
For two sets A and B:

The overlapping region represents: A ∩ B

Both circles together represent: A ∪ B

⚡ Exam Trick:
When you see a Venn diagram: Overlap = Intersection
All selected regions = Union
Outside A but inside U = A′

1.8 Cardinality of Sets

The number of elements in a set is called the cardinality of the set. It is written as n(A) or |A|.
A = {2,4,6,8} Therefore: n(A) = 4

Union Formula

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

We subtract the intersection because common elements were counted twice.

n(A) = 20 n(B) = 15 n(A ∩ B) = 5 Therefore: n(A ∪ B) = 20 + 15 − 5 = 30
⚡ Short Trick:
For two sets remember: Total = A + B − Common

1.9 Applications of Sets

Sets are useful in real-life situations where objects need to be grouped or compared.

Example

Suppose 30 students study Mathematics, 20 study Physics, and 10 study both.

Number studying at least one: 30 + 20 − 10 = 40

This type of problem can be represented using a Venn diagram.

Important words:
  • "A or B" → A ∪ B
  • "A and B" → A ∩ B
  • "not A" → A′
  • "only A" → A − B
  • "at least one" → Union
  • "both" → Intersection

🎯 Unit 1 Exam Tips

  • Do not count repeated elements twice.
  • Remember that order does not matter in sets.
  • Always identify the universal set before finding a complement.
  • For union, combine elements without repetition.
  • For intersection, take only common elements.
  • For cardinality of two sets, subtract the common part once.
  • In Venn diagrams, carefully read what each region represents.
