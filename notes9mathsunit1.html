📘 Unit 1: Further on Sets

This lesson introduces important ideas about sets, subsets, universal sets, operations on sets, Venn diagrams and applications of sets.

1️⃣ What is a Set?

A set is a well-defined collection of distinct objects. The objects in a set are called elements or members.

Example:

A = {1, 2, 3, 4, 5}

Here, 1, 2, 3, 4 and 5 are the elements of set A.

Set notation

If x belongs to set A, we write:

x ∈ A

If x does not belong to A, we write:

x ∉ A

2️⃣ Ways of Describing a Set

A. Roster or Listing Method

The elements are listed inside curly brackets.

A = {2, 4, 6, 8, 10}

B. Set-Builder Method

The elements are described using a rule or property.

A = {x | x is an even natural number less than 12}

3️⃣ Types of Sets

Finite Set

A set containing a limited number of elements.

A = {1, 2, 3, 4}

Infinite Set

A set whose elements continue without end.

N = {1, 2, 3, 4, 5, ...}

Empty Set

A set containing no elements.

∅ or { }

Singleton Set

A set containing exactly one element.

A = {7}

4️⃣ Cardinality of a Set

The number of elements in a set is called its cardinality.

n(A) = number of elements in A
If: A = {2, 4, 6, 8} then: n(A) = 4

5️⃣ Subsets

Set A is a subset of set B if every element of A is also an element of B.

A ⊆ B
A = {1, 2} B = {1, 2, 3, 4} Therefore: A ⊆ B

Proper Subset

A is a proper subset of B when A is a subset of B but A is not equal to B.

A ⊂ B

6️⃣ Universal Set

The universal set contains all the elements under consideration in a particular problem.

It is usually represented by U.

U = {1,2,3,4,5,6} A = {2,4,6} Here A is a subset of U.

7️⃣ Complement of a Set

The complement of A contains all elements in the universal set that are not in A.

A' = U − A
U = {1,2,3,4,5,6} A = {2,4,6} Therefore: A' = {1,3,5}

8️⃣ Union of Sets

The union of two sets contains all elements that belong to either set, without repeating elements.

A ∪ B
A = {1,2,3} B = {3,4,5} A ∪ B = {1,2,3,4,5}

9️⃣ Intersection of Sets

The intersection contains elements that are common to both sets.

A ∩ B
A = {1,2,3} B = {2,3,4} A ∩ B = {2,3}

🔟 Difference of Sets

The difference A − B contains elements that belong to A but do not belong to B.

A − B
A = {1,2,3,4} B = {3,4,5} A − B = {1,2}

📊 Venn Diagrams

A Venn diagram is a visual representation of sets. Circles are commonly used to represent sets.

  • Union → A ∪ B
  • Intersection → A ∩ B
  • Complement → A'
  • Difference → A − B

🧠 Important Laws of Sets

Law Relationship
Identity A ∪ ∅ = A
Identity A ∩ U = A
Domination A ∪ U = U
Domination A ∩ ∅ = ∅
Complement A ∪ A' = U
Complement A ∩ A' = ∅
Idempotent A ∪ A = A
Idempotent A ∩ A = A

🎯 Exam Tips

  • Do not repeat an element when finding a union.
  • Intersection means COMMON elements.
  • Complement means elements OUTSIDE the set.
  • Always check the universal set before finding a complement.
  • Remember: ∪ means OR, while ∩ means AND.
