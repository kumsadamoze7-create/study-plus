📘 Unit 1: Functions

What is a Function?

A function is a relationship where each input has exactly one output.

Example

f(x) = 2x + 3

When x = 2:

f(2) = 2(2) + 3

f(2) = 7

⭐ Remember

In a function, one input cannot have two different outputs.

📘 Example 2

Find f(5) if f(x) = x² + 1.

f(5) = 5² + 1

= 25 + 1

= 26
