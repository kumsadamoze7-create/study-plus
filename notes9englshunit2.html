🇬🇧 Grade 9 English

Unit 2 — Conditional Sentences

Complete Notes • Forms • Rules • Exam Tricks

📘 What is a Conditional Sentence?

A conditional sentence expresses a condition and its possible, usual, imaginary, or past result.

Example:

If I study hard, I will pass the exam.

A conditional sentence normally has two parts:

  • Condition / If-clause: If I study hard
  • Result / Main clause: I will pass the exam
If I study hard, I will pass the exam.

I will pass the exam if I study hard.

When the if-clause comes first, we normally use a comma.

1️⃣ Zero Conditional

The Zero Conditional is used for general truths, scientific facts, rules, habits and things that normally or always happen.

If + Simple Present, Simple Present

Examples

If you heat water, it boils.

If ice gets warm, it melts.

If you don't eat, you become hungry.
🔥 Exam Trick:
If the sentence describes a general fact or scientific truth, think about Zero Conditional.

2️⃣ First Conditional

The First Conditional is used for real or possible situations in the present or future.

If + Simple Present, will + V1

Examples

If I study hard, I will pass the exam.

If it rains, we will stay at home.

If you hurry, you will catch the bus.

⚠️ Important Rule

❌ If I will study, I will pass.

✅ If I study, I will pass.
🔥 Shortcut:
If + Present → will + V1

3️⃣ Second Conditional

The Second Conditional is used for imaginary, unlikely, or unreal situations in the present or future.

If + Simple Past, would + V1

Examples

If I had a million dollars, I would buy a house.

If she studied harder, she would pass the exam.

If I were you, I would study harder.

⭐ Special Rule — WERE

In formal English, were is commonly used with I, he, she and it in unreal conditional expressions.

If I were you, I would accept the offer.

If he were here, he would help us.
🔥 Exam Trick:
If + Past → would + V1 Remember: If I were you...

4️⃣ Third Conditional

The Third Conditional is used for unreal or impossible past situations. It often expresses regret or imagines a different past result.

If + Past Perfect, would have + V3

Examples

If I had studied, I would have passed the exam.

If she had arrived early, she would have caught the bus.

If they had worked harder, they would have won.
🔥 Shortcut:
If + had + V3 → would have + V3
❌ If I had studied, I would pass.

✅ If I had studied, I would have passed.

🔄 Inverted Conditional

In formal English, some conditional sentences can be inverted. The word if is removed and an auxiliary verb moves before the subject.

A. HAD — Inverted Third Conditional

If + S + had + V3 ↓ Had + S + V3
If I had known, I would have helped you.

➡️ Had I known, I would have helped you.

B. WERE — Inverted Second Conditional

If + S + were ↓ Were + S
If I were you, I would accept it.

➡️ Were I you, I would accept it.

C. SHOULD — Inverted Conditional

If + S + should + V1 ↓ Should + S + V1
If you need any help, call me.

➡️ Should you need any help, call me.
🔥 Exam Trick:
If a sentence starts with: Had / Were / Should check whether it is an inverted conditional.

5️⃣ Unless

Unless generally means: If ... not

Unless + affirmative clause + result
Unless you study, you will fail.

= If you don't study, you will fail.

⚠️ Important

❌ Unless you don't study...

✅ Unless you study...

Unless already has a negative meaning, so we normally do not add another not.

6️⃣ Provided / Providing that

Provided that and providing that mean approximately if or on the condition that.

You can go out provided that you finish your homework.

I will help you providing that you tell me the truth.
🔥 provided that = if

🔥 providing that = if

7️⃣ As long as

As long as can mean if or provided that when it introduces a condition.

You can use my phone as long as you are careful.

I will come as long as you invite me.

It can also describe duration.

I will stay here as long as you need me.

8️⃣ In case

In case is commonly used for a precaution. Something may happen, so you prepare for it.

Take an umbrella in case it rains.

In case vs If

If it rains, I will take an umbrella.
Rain is the condition for taking the umbrella.

I will take an umbrella in case it rains.
I take it now as a precaution.
🔥 Exam Trick:
In case → precaution.

9️⃣ If only

If only expresses a strong wish, regret, or desire for a different situation.

Present Unreal

If only + Past Simple
If only I had more money!

If only I were taller!

Past Regret

If only + Past Perfect
If only I had studied harder!

If only I had not missed the bus!

🔟 Wish

A. Wish about Present

wish + Past Simple
I wish I had more money.

She wishes she were here.

B. Wish about Past

wish + Past Perfect
I wish I had studied harder.

He wishes he had not missed the bus.

C. Wish for Change

wish + would + V1
I wish you would stop making noise.

I wish it would stop raining.
🔥 Exam Shortcut:

Present unreal → wish + Past
Past regret → wish + Past Perfect
Desired change → wish + would + V1

1️⃣1️⃣ Mixed Conditionals

Mixed conditionals combine different time references.

Past Condition → Present Result

If + Past Perfect, would + V1
If I had studied medicine, I would be a doctor now.

Present Condition → Past Result

If + Past Simple, would have + V3
If I were more careful, I wouldn't have made that mistake.
🔥 If the condition and result refer to different times, check for Mixed Conditional.

📊 Four Main Conditional Types

Type If-Clause Result Use
Zero Present Present Fact / General Truth
First Present will + V1 Real Future Possibility
Second Past would + V1 Unreal / Unlikely
Third had + V3 would have + V3 Unreal Past / Regret

🔥 Final Exam Tricks

  • Present + Present → Zero Conditional
  • Present + will → First Conditional
  • Past + would → Second Conditional
  • had + V3 + would have + V3 → Third Conditional
  • Had + subject + V3 → Inverted Third
  • Were + subject → Inverted Second
  • Should + subject + V1 → Inverted Conditional
  • Unless → usually means if...not
  • Provided that → condition
  • As long as → condition / duration
  • In case → precaution
  • Wish + Past → present unreal
  • Wish + Past Perfect → past regret
  • Wish + would → desired change
  • Do not normally put will directly after if in an ordinary first conditional.
  • Do not add not unnecessarily after unless.
