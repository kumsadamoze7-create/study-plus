Unit 1 — Further on Sets

1. What is a Set?

A set is a well-defined collection of objects. The objects in a set are called elements.

Example:
A = {2, 4, 6, 8}

2, 4, 6 and 8 are elements of A.

2. Set Notation

x ∈ A means x is an element of A.

x ∉ A means x is not an element of A.

3. Types of Sets

Empty Set: A set with no elements.

A = ∅

Finite Set: A set with a limited number of elements.

Infinite Set: A set whose elements continue without end.

4. Cardinality

Cardinality means the number of elements in a set.

A = {1, 3, 5, 7}

n(A) = 4
⚡ Short Trick: Repeated elements are counted only once.

5. Subset

A is a subset of B if every element of A is also an element of B.

A ⊆ B
A = {1, 2}
B = {1, 2, 3, 4}

Therefore A ⊆ B.

6. Power Set

The power set is the set containing all subsets of a set.

A = {a, b}

P(A) = {∅, {a}, {b}, {a,b}}
Number of subsets = 2ⁿ
⚡ If a set has 5 elements: 2⁵ = 32 subsets.

7. Union

Union contains all elements that belong to A or B.

A ∪ B
A = {1,2,3}
B = {3,4,5}

A ∪ B = {1,2,3,4,5}
⚡ Union = OR

8. Intersection

Intersection contains elements common to both sets.

A ∩ B
A = {1,2,3}
B = {3,4,5}

A ∩ B = {3}
⚡ Intersection = AND

9. Difference of Sets

A − B contains elements that are in A but not in B.

A = {1,2,3}
B = {3,4,5}

A − B = {1,2}

10. Complement

The complement of A contains elements in the universal set that are not in A.

Aᶜ = U − A

11. Important Formula

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
⚡ Exam Trick:
Add A + B, then subtract the common part.
Example:

n(A) = 35
n(B) = 28
n(A ∩ B) = 12

n(A ∪ B) = 35 + 28 − 12 = 51
🎯 Exam Words:

"at least one" → Union
"both" → Intersection
"neither" → Total − Union
