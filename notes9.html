1. Sets and Elements

Definition

A set is a well-defined collection of distinct objects. The objects belonging to a set are called elements or members.

Example:
A = {2, 4, 6, 8}

2, 4, 6 and 8 are the elements of A.

Symbols

∈ means "is an element of".

∉ means "is not an element of".

If A = {2, 4, 6, 8}:

4 ∈ A ✅
5 ∉ A ✅
⚡ Short Trick: ∈ means "inside the set".

2. Set Description

A set can be described in different ways. The three important methods are descriptive form, roster form and set-builder form.

A. Descriptive Form

We describe the members of the set using words.

Example:
A = set of even natural numbers less than 10.

B. Roster / Tabular Form

We list all the elements inside curly brackets.

A = {2, 4, 6, 8}

C. Set-Builder Form

We describe a set using a rule or condition.

A = {x : x is an even natural number and x < 10}
Example:

B = {1, 2, 3, 4, 5}

Set-builder form:
B = {x : x ∈ N, x ≤ 5}
⚡ Exam Trick:
Roster → list the elements.
Set-builder → write the rule.

3. Types of Sets

1. Empty Set

A set containing no element is called an empty or null set.

A = ∅

It can also be written as:

A = { }

2. Singleton Set

A set containing exactly one element.

A = {5}

n(A) = 1

3. Finite Set

A set having a definite number of elements.

A = {1, 2, 3, 4}

4. Infinite Set

A set whose elements continue indefinitely.

N = {1, 2, 3, 4, 5, ...}

5. Equal Sets

Two sets are equal if they contain exactly the same elements.

A = {1, 2, 3}
B = {3, 2, 1}

Therefore A = B.
⚡ Order does NOT matter in a set.

6. Equivalent Sets

Two sets are equivalent if they have the same number of elements.

A = {1, 2, 3}
B = {a, b, c}

n(A) = n(B) = 3
Therefore A and B are equivalent.

7. Universal Set

The universal set contains all objects under consideration in a particular problem.

U = Universal Set

4. Subsets and Proper Subsets

Subset

A is a subset of B if every element of A is also an element of B.

A ⊆ B
A = {1, 2}
B = {1, 2, 3, 4}

A ⊆ B

Proper Subset

A is a proper subset of B if every element of A is in B, but A and B are not equal.

A ⊂ B
A = {1, 2}
B = {1, 2, 3}

A ⊂ B

Subset vs Proper Subset

A ⊆ B: A may be equal to B.

A ⊂ B: A must NOT be equal to B.

Number of Subsets

Number of subsets = 2ⁿ

where n is the number of elements in the set.

A = {a, b, c}

n = 3
Number of subsets = 2³ = 8

Number of Proper Subsets

Number of proper subsets = 2ⁿ − 1
If n = 4:

Proper subsets = 2⁴ − 1
= 16 − 1
= 15
⚡ Remember:
All subsets → 2ⁿ
Proper subsets → 2ⁿ − 1
⚠️ The empty set ∅ is a subset of every set.

5. Cardinality of a Set

Cardinality means the number of distinct elements in a set.

n(A) = number of elements in A
A = {2, 4, 6, 8}

n(A) = 4
⚠️ Repeated elements are counted only once.

A = {1, 1, 2, 2, 3}
n(A) = 3

6. Union of Sets

The union of A and B contains every element that belongs to A, B, or both.

A ∪ B
A = {1, 2, 3}
B = {3, 4, 5}

A ∪ B = {1, 2, 3, 4, 5}
⚡ Union = OR

Cardinality Formula

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
n(A) = 20
n(B) = 15
n(A ∩ B) = 5

n(A ∪ B) = 20 + 15 − 5
= 30

7. Intersection of Sets

The intersection contains the elements common to both sets.

A ∩ B
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

A ∩ B = {3, 4}
⚡ Intersection = AND / Common elements
If two sets have no common element:

A ∩ B = ∅

They are called disjoint sets.

8. Difference of Sets

A − B contains elements that are in A but not in B.

A − B
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

A − B = {1, 2}

B − A = {5, 6}
⚠️ Difference is NOT commutative.

A − B ≠ B − A in general.
⚡ A − B → Start from A and remove everything that is in B.

9. Complement of a Set

The complement of A contains all elements of the universal set that are not in A.

Aᶜ = U − A
U = {1, 2, 3, 4, 5, 6}
A = {1, 3, 5}

Aᶜ = {2, 4, 6}
⚡ Complement = Everything in U except A.

10. Laws of Sets

Commutative Laws

A ∪ B = B ∪ A

A ∩ B = B ∩ A

Associative Laws

(A ∪ B) ∪ C = A ∪ (B ∪ C)

(A ∩ B) ∩ C = A ∩ (B ∩ C)

Distributive Laws

A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)

A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

Identity Laws

A ∪ ∅ = A

A ∩ U = A

Domination Laws

A ∪ U = U

A ∩ ∅ = ∅

Idempotent Laws

A ∪ A = A

A ∩ A = A

Complement Laws

A ∪ Aᶜ = U

A ∩ Aᶜ = ∅

11. De Morgan's Laws

These laws are very important for solving more complex set problems.

(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ

(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
⚡ Short Trick:
When complement enters the bracket:

∪ changes to ∩
∩ changes to ∪

12. Venn Diagram and Applications

A Venn diagram represents sets using circles inside a universal set.

Two Important Regions

The overlapping region represents:

A ∩ B

The complete area belonging to A or B represents:

A ∪ B

Important Formula

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
Complex Example:

In a class of 60 students:
35 study Mathematics.
28 study Physics.
12 study both.

Students studying at least one:

35 + 28 − 12 = 51

Therefore 51 students study at least one subject.

Students studying neither:

60 − 51 = 9
🎯 Exam Words:

"both" → A ∩ B
"at least one" → A ∪ B
"neither" → Total − Union
"only A" → A − B
"only B" → B − A

13. Three-Set Formula

For three sets, the inclusion-exclusion formula is:

n(A ∪ B ∪ C) = n(A)+n(B)+n(C) −n(A∩B) −n(A∩C) −n(B∩C) +n(A∩B∩C)
⚡ Memory Trick:

+ singles
− pairs
+ triple
Suppose:

n(A)=30
n(B)=25
n(C)=20
n(A∩B)=10
n(A∩C)=8
n(B∩C)=7
n(A∩B∩C)=4

n(A∪B∪C)
= 30+25+20−10−8−7+4
= 54

15. ⚠️ Common Mistakes

❌ Mistake 1: Counting repeated elements twice.

❌ Mistake 2: Thinking A − B = B − A.

❌ Mistake 3: Forgetting to subtract the intersection in a union problem.

❌ Mistake 4: Confusing subset with proper subset.

❌ Mistake 5: Forgetting that ∅ is a subset of every set.

❌ Mistake 6: Forgetting the universal set when finding a complement.
