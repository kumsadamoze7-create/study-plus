📘 Unit 2 Overview

The number system is the way numbers are classified and organized. In this unit we study integers, rational numbers, irrational numbers and real numbers, together with their properties and operations.

Understanding the number system is important because almost every topic in mathematics uses numbers.

⚡ Big Picture:

Natural ⊂ Whole ⊂ Integers ⊂ Rational ⊂ Real

Irrational numbers are also real numbers, but they are not rational.

2.1 Natural Numbers

Natural numbers are the positive counting numbers.

N = {1, 2, 3, 4, 5, ...}

They are commonly used for counting objects.

There are 5 students. The number 5 is a natural number.
⚡ Remember:
Natural numbers start at 1 in the common school definition.

2.2 Whole Numbers

Whole numbers are the natural numbers together with zero.

W = {0, 1, 2, 3, 4, ...}

0 is a whole number. 1 is a whole number. 25 is a whole number.
⚡ Shortcut:
Whole numbers = Natural numbers + 0

2.3 Integers

Integers include positive whole numbers, zero and negative whole numbers.

Z = {..., -3, -2, -1, 0, 1, 2, 3, ...}

Examples

  • 7 is an integer.
  • 0 is an integer.
  • -12 is an integer.
  • 2.5 is not an integer.
  • 1/3 is not an integer.

Positive and Negative Integers

Positive integers are greater than zero.

Negative integers are less than zero.

On a number line:

Negative ← —— 0 —— → Positive
⚡ Number Line Trick:
The farther right a number is, the greater it is. Therefore: -2 > -5 because -2 is to the right of -5.

2.4 Rational Numbers

A rational number is any number that can be written in the form:
a / b

where a and b are integers and b ≠ 0.

Examples

  • 1/2
  • -3/4
  • 5 = 5/1
  • 0 = 0/1
  • 0.75 = 3/4

Terminating Decimals

A decimal that ends is rational.

0.5 = 1/2
0.25 = 1/4
2.75 = 11/4

Repeating Decimals

A decimal that repeats a pattern forever is also rational.

0.333... = 1/3
0.666... = 2/3
⚡ Quick Test:
Terminating decimal → Rational ✔️ Repeating decimal → Rational ✔️ Non-terminating and non-repeating → Irrational ❌

2.5 Irrational Numbers

An irrational number cannot be expressed as a fraction of two integers.

Examples

  • √2
  • √3
  • √5
  • π

Their decimal representations continue forever without repeating a fixed pattern.

√2 ≈ 1.41421356... The digits continue without a repeating pattern.
⚠️ Important:
Not every square root is irrational. For example: √9 = 3 Since 3 is an integer, √9 is rational.
⚡ Square Root Trick:
If the number inside √ is a perfect square, the result is rational. If it is not a perfect square, the square root is irrational.

2.6 Real Numbers

Real numbers consist of all rational and irrational numbers.
Real Numbers = Rational Numbers ∪ Irrational Numbers

Examples

  • 5
  • -2
  • 3/4
  • 0.25
  • √2
  • π
⚡ Remember:
Almost every number you normally use on a number line is a real number.

2.8 Comparing and Ordering Real Numbers

Real numbers can be compared using <, > and =.

Compare: -3 and -7

Since -3 is farther right on the number line: -3 > -7

Ordering from Least to Greatest

Arrange: 3, -2, 0, -5, 4

Answer: -5, -2, 0, 3, 4
⚡ Trick:
For negative numbers, the number with the larger absolute value is actually smaller.

-10 < -3

2.9 Absolute Value

The absolute value of a number is its distance from zero on the number line.
|a| = distance of a from 0
|5| = 5
|-5| = 5
|0| = 0

Absolute value is never negative.

⚡ Remember:
Absolute value = Distance

Distance can never be negative.

2.10 Operations with Integers

Addition

5 + 3 = 8
-5 + (-3) = -8
5 + (-3) = 2

Subtraction

a − b = a + (-b)
5 − (-3) = 5 + 3 = 8

Multiplication and Division

Signs Result
+ × + +
− × − +
+ × − −
− × + −
⚡ Sign Trick:

Same signs → Positive ✔️
Different signs → Negative ✔️

2.11 Properties of Real Numbers

Commutative Property

a + b = b + a

a × b = b × a

Associative Property

(a + b) + c = a + (b + c)

(a × b) × c = a × (b × c)

Distributive Property

a(b + c) = ab + ac
3(4 + 2) = 3×4 + 3×2 = 12 + 6 = 18
⚡ FOIL / Distribution Trick:
When a number is outside brackets, multiply it by every term inside.

2.12 Laws of Exponents

Product Rule

aᵐ × aⁿ = aᵐ⁺ⁿ
2² × 2³ = 2⁵ = 32

Quotient Rule

aᵐ ÷ aⁿ = aᵐ⁻ⁿ

Power of a Power

(aᵐ)ⁿ = aᵐⁿ

Zero Exponent

a⁰ = 1
a ≠ 0

Negative Exponent

a⁻ⁿ = 1/aⁿ
⚡ Exponent Trick:
Multiply same base → Add powers
Divide same base → Subtract powers
Power of power → Multiply powers

2.13 Scientific Notation

Scientific notation expresses very large or very small numbers using powers of 10.

a × 10ⁿ

where 1 ≤ |a| < 10
450000
= 4.5 × 10⁵
0.00032
= 3.2 × 10⁻⁴
⚡ Decimal Trick:
Large number → positive exponent.
Small decimal → negative exponent.

2.14 Square Roots

The square root of a number is a value which, when multiplied by itself, gives the original number.

√25 = 5 because: 5 × 5 = 25

2.15 Approximation and Estimation

Sometimes an exact value is not necessary. We can use an approximate value to make calculations easier.

√2 ≈ 1.414
π ≈ 3.14

Rounding

If the next digit is 5 or greater, increase the previous digit by 1. If the next digit is less than 5, leave the previous digit unchanged.

3.746 rounded to 2 decimal places: 3.75
⚡ 5 or more → Round UP
Less than 5 → Stay

🎯 Unit 2 Exam Tips

  • Do not confuse integers with rational numbers.
  • Every integer is rational because n = n/1.
  • Every rational and irrational number is real.
  • A terminating decimal is rational.
  • A repeating decimal is rational.
  • A non-terminating, non-repeating decimal is irrational.
  • √perfect square is rational.
  • √non-perfect square is usually irrational.
  • Absolute value represents distance from zero.
  • For negative numbers, farther left means smaller.
  • Same signs in multiplication/division give positive results.
  • Different signs give negative results.
