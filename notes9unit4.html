Unit 4 — Solving Inequalities

Study Plus • Complete Notes • Examples • Entrance Tricks

⭐ Unit 4 Overview

An inequality compares two expressions using inequality symbols. Unlike an equation, an inequality usually has a range of possible answers.

x < a    x > a    x ≤ a    x ≥ a
Meaning of symbols:

< → less than
> → greater than
≤ → less than or equal to
≥ → greater than or equal to

4.1 Revision: Linear Inequalities in One Variable

Definition

A linear inequality in one variable is an inequality containing one variable whose highest power is 1.

ax + b < c

where a, b and c are real numbers and a ≠ 0.

Basic Rules

If we add or subtract the same number from both sides, the inequality sign does not change.

If we multiply or divide both sides by a positive number, the sign does not change.

If we multiply or divide both sides by a negative number, reverse the inequality sign.

Example 1

Solve:

3x + 5 > 14

3x > 9

x > 3

Example 2 — Negative Coefficient

Solve:

−2x + 4 ≥ 10

−2x ≥ 6

Divide by −2.

x ≤ −3
⚠️ Because we divided by a negative number, ≥ changed to ≤.

Number Line

x > 3

Use an open circle at 3 because 3 is NOT included.

Shade to the right.

x ≥ 3

Use a closed circle because 3 IS included.
🎯 Entrance Trick:

< or > → Open circle
≤ or ≥ → Closed circle

Greater → Right
Less → Left

4.2 Systems of Linear Inequalities in Two Variables

Definition

A system of inequalities contains two or more inequalities involving the same variables.

Example:

y ≥ x + 1
y < −x + 5

The solution is the region of the coordinate plane that satisfies both inequalities.

Graphical Method

Step 1: Change the inequality temporarily into an equation to obtain the boundary line.
Step 2: Graph the boundary line.
Step 3: Determine whether the boundary is solid or dashed.
Step 4: Choose a test point.
Step 5: Shade the correct side.
Step 6: The common shaded region is the solution.

Solid vs Dashed Line

≤ or ≥ → Solid line

< or > → Dashed line

Example

Solve graphically:

y ≥ x + 1
y ≤ −x + 5

The first boundary is:
y = x + 1

The second boundary is:
y = −x + 5

Both signs include equality, therefore both boundary lines are solid. The solution is the region where the two shaded regions overlap.
⚡ Graph Trick:

≥ → shade ABOVE the line
≤ → shade BELOW the line
But always check with a test point when unsure.

⭐ Test Point Method

To determine which side of a boundary line should be shaded, choose a point that is not on the line.

Example

For:

y > 2x + 1

Choose (0,0).

0 > 2(0) + 1
0 > 1

This is FALSE. Therefore the side containing (0,0) is NOT the solution.
🎯 If the test point makes the inequality TRUE, shade the side containing that point. If FALSE, shade the opposite side.

4.3 Inequalities Involving Absolute Value

Absolute Value

Absolute value represents distance from zero on the number line. Therefore it is always non-negative.

|x| ≥ 0
|5| = 5
|−5| = 5
|0| = 0
0

Basic Absolute Value Inequality Rules

|x| < a    means    −a < x < a

|x| ≤ a    means    −a ≤ x ≤ a
|x| > a    means    x < −a   OR   x > a

|x| ≥ a    means    x ≤ −a   OR   x ≥ a
⭐ Easy Memory Trick:

< → AND → inside
> → OR → outside

Example 1

Solve:

|x| < 4

Therefore:
−4 < x < 4

Solution:
(−4, 4)

Example 2

Solve:

|x| ≥ 3

Therefore:
x ≤ −3 OR x ≥ 3

Example 3

Solve:

|2x − 1| ≤ 5

−5 ≤ 2x − 1 ≤ 5

Add 1:
−4 ≤ 2x ≤ 6

Divide by 2:
−2 ≤ x ≤ 3

Graphing Absolute Value Inequalities

Absolute Value Function

y = |x|

The graph of y = |x| has a V-shape and its vertex is at (0,0).

Example

Graph:

y ≥ |x|

First draw:
y = |x|

Because ≥ includes equality, use a solid boundary.

Shade the region above the V-shaped graph.
For:

y < |x|

Use a dashed boundary and shade the region below the graph.
🎯 Graph Trick:

≥ or ≤ → solid boundary
> or < → dashed boundary

4.4 Quadratic Inequalities

Definition

A quadratic inequality contains a variable with highest power 2.

ax² + bx + c > 0
ax² + bx + c < 0
ax² + bx + c ≥ 0
ax² + bx + c ≤ 0

Example

x² − 5x + 6 > 0

This is a quadratic inequality because the highest power of x is 2.

Quadratic Inequalities Using Product Properties

First factor the quadratic expression, find its critical values, then determine where the product has the required sign.

Example

Solve:

x² − 5x + 6 > 0

Factor:
(x − 2)(x − 3) > 0

Critical values:
x = 2 and x = 3
The critical values divide the number line into three intervals:

1. x < 2
2. 2 < x < 3
3. x > 3
Test one number from each interval.

For x = 1:
(1−2)(1−3) = (+)

For x = 2.5:
(2.5−2)(2.5−3) = (−)

For x = 4:
(4−2)(4−3) = (+)

Therefore:

x < 2 OR x > 3
Because the inequality is >, the roots 2 and 3 are NOT included.

Quadratic Inequalities Using Sign Chart

A sign chart shows whether each factor is positive or negative in each interval.

Example

Solve:

(x − 2)(x − 3) ≤ 0
Critical values:

2 and 3

Intervals:
(−∞,2), (2,3), (3,∞)
Sign pattern:

x < 2 → (+)
2 < x < 3 → (−)
x > 3 → (+)
We need ≤ 0, so choose the negative region and include the points where the expression equals zero.

Solution:
2 ≤ x ≤ 3
⭐ Sign Chart Shortcut:

For two simple factors with positive leading coefficient:

Outside → +
Inside → −

So:
> 0 → outside
< 0 → inside

⭐ Including or Excluding the Roots

> or < → roots are NOT included.

≥ or ≤ → roots ARE included.
(x − 2)(x − 3) > 0

Solution:
x < 2 OR x > 3

2 and 3 are excluded.
(x − 2)(x − 3) ≥ 0

Solution:
x ≤ 2 OR x ≥ 3

2 and 3 are included.

⭐ Effect of the Leading Coefficient

For a quadratic expression, the sign of the coefficient of x² helps determine the sign pattern.

For:

(x − 2)(x − 3)

Leading coefficient is positive.
Sign pattern:

+ , − , +
For:

−(x − 2)(x − 3)

The signs reverse:

− , + , −
🎯 Entrance Trick:

Positive leading coefficient:
+ − +

Negative leading coefficient:
− + −

🔥 Complete Quadratic Inequality Example

Solve:

x² − x − 6 ≥ 0

Factor:
(x − 3)(x + 2) ≥ 0

Critical values:
x = 3 and x = −2
Intervals:

x < −2
−2 < x < 3
x > 3
Sign pattern:

+    −    +
We need ≥ 0. Therefore choose positive regions and include the roots.

Solution:

x ≤ −2 OR x ≥ 3

📌 Interval Notation

Interval notation is a short way of writing inequality solutions.

x > 2 → (2, ∞)

x ≥ 2 → [2, ∞)

x < 2 → (−∞, 2)

x ≤ 2 → (−∞, 2]
( ) → endpoint NOT included

[ ] → endpoint included

🏆 Entrance Exam Short Tricks

1. Negative multiplication/division → reverse the inequality sign.

2. < or > → open circle.

3. ≤ or ≥ → closed circle.

4. Greater → right.

5. Less → left.

6. Absolute value < → AND / inside.

7. Absolute value > → OR / outside.

8. Quadratic inequality → factor → roots → intervals → signs.

9. Positive quadratic leading coefficient → + − +.

10. Negative quadratic leading coefficient → − + −.

11. > or < → exclude roots.

12. ≥ or ≤ → include roots.

13. Two-variable inequality → graph boundary → test point → shade.

⚠️ Common Mistakes

❌ Mistake 1: Forgetting to reverse the sign when dividing by a negative number.

❌ Mistake 2: Using a solid line for < or >.

❌ Mistake 3: Using a dashed line for ≤ or ≥.

❌ Mistake 4: Forgetting that |x| < a means AND.

❌ Mistake 5: Forgetting that |x| > a means OR.

❌ Mistake 6: Including roots when the inequality is strict.

❌ Mistake 7: Not checking the sign of each interval in a quadratic inequality.

❌ Mistake 8: Confusing the solution region with the boundary line.

🧠 Unit 4 Final Summary

Linear inequality:
Solve normally, but reverse the sign when multiplying/dividing by a negative number.

Two-variable system:
Graph → test point → shade → intersection.

Absolute value:
|x| < a → −a < x < a

|x| > a → x < −a OR x > a

Quadratic inequality:
Factor → find roots → make intervals → sign chart → choose solution.
🔥 MASTER TRICK:

Linear → watch the negative sign.

Absolute value → remember AND / OR.

Graphical → solid/dashed + correct shading.

Quadratic → roots + sign chart.
