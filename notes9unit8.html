8.1 Vector and Scalar Quantities

Scalar Quantity

A scalar quantity has magnitude only.

Examples:

Mass = 5 kg
Time = 10 seconds
Temperature = 25°C
Distance = 20 m
Speed = 60 km/h

Vector Quantity

A vector quantity has both magnitude and direction.

Examples:

Displacement
Velocity
Acceleration
Force
Scalar: Magnitude only.

Vector: Magnitude + Direction.
⚡ Memory Trick:

Scalar → Size only.
Vector → Size + Direction.

8.2 Representation of a Vector

A vector is commonly represented by a directed line segment. The arrow shows the direction of the vector.

Vector AB = →AB

A is called the initial point and B is called the terminal point.

Equality of Vectors

Two vectors are equal if they have the same magnitude and the same direction.

a = b

Opposite Vectors

Opposite vectors have the same magnitude but opposite directions.

−a
If:
a = 5 m east

then:
−a = 5 m west.

Parallel Vectors

Vectors are parallel if they have the same or opposite direction along parallel lines.

a ∥ b

Column Vector in Two Dimensions

A vector in two dimensions can be represented using a column vector.

a =
⎡ x ⎤
⎣ y ⎦

x represents the horizontal component and y represents the vertical component.

Example:

a =
⎡ 3 ⎤
⎣ 4 ⎦

This means:
3 units horizontally
4 units vertically.

Magnitude of a Vector

The magnitude of a vector is its length.

|a| = √(x² + y²)
Given:
a = ⎡3⎤
⎣4⎦

|a| = √(3² + 4²)
= √(9 + 16)
= √25
= 5
⚡ Think of the magnitude formula as the Pythagorean theorem.

Direction of a Vector

The direction of a vector can be measured using an angle θ from the positive x-axis.

tan θ = y / x

Therefore:

θ = tan⁻¹(y/x)
For:
x = 3
y = 4

tan θ = 4/3
θ ≈ 53.1°

Triangle Law of Vector Addition

If two vectors are placed head-to-tail, the vector from the starting point to the final point represents their sum.

Parallelogram Law of Vector Addition

When two vectors start from the same point, the diagonal of the parallelogram represents their sum.

8.4 Position Vector

A position vector describes the position of a point relative to the origin.

OP = p

where O is the origin and P is the point.

If:
P = (4, 3)

then the position vector of P is:
OP =
⎡4⎤
⎣3⎦

Vector Between Two Points

If A and B have position vectors a and b, then the vector from A to B is:

AB = b − a

8.5 Applications of Vectors in Two Dimensions

Vectors are used to solve many real-life problems.

1. Displacement

Vectors can represent movement from one point to another.

2. Velocity

Velocity describes speed together with direction.

3. Force

Forces have both magnitude and direction, so they can be represented by vectors.

4. Navigation

Vectors can be used to describe movement in different directions.

5. Engineering and Physics

Vectors are used to represent forces, motion, acceleration and displacement.

⭐ Exam Short Tricks

1. Scalar → magnitude only.

2. Vector → magnitude + direction.

3. Equal vectors → same magnitude + same direction.

4. Opposite vectors → same magnitude + opposite direction.

5. Magnitude → √(x² + y²)

6. Direction → tan⁻¹(y/x)

7. Addition → add corresponding components.

8. Subtraction → subtract corresponding components.

9. Scalar multiplication → multiply every component.

10. Position vector → vector from origin to point.
