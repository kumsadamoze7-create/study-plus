⭐ Unit 3 Overview

An equation is a mathematical statement showing that two expressions are equal.

Left side = Right side
Example:

2x + 5 = 15

The goal is to find the value of x that makes the equation true.
🎯 Main idea:

Whatever operation you perform on one side of an equation, you must perform the same operation on the other side.

3.1 Revision on Linear Equation in One Variable

Definition

A linear equation in one variable is an equation in which the highest power of the variable is 1.

ax + b = 0,   a ≠ 0

Example 1

Solve:

3x + 5 = 20

3x = 20 − 5
3x = 15
x = 5

Example 2

Solve:

5x − 7 = 18

5x = 25
x = 5

Equation with fractions

Solve:

x/3 + 2 = 6

x/3 = 4
x = 12

Equation with brackets

Solve:

3(x + 2) = 18

3x + 6 = 18
3x = 12
x = 4
⚡ Short Trick:

Move a term across "=" → its sign changes.

+ becomes −
− becomes +
× becomes ÷
÷ becomes ×
⚠️ Always check your answer by substituting it back into the original equation.

3.2 System of Linear Equations in Two Variables

A system of linear equations contains two or more equations with two variables.

ax + by = c
dx + ey = f
Example:

x + y = 7
x − y = 1

Meaning of Solution

The solution is an ordered pair (x,y) that satisfies both equations.

For the example above:

Add the equations:
(x+y)+(x−y)=7+1
2x=8
x=4

Substitute:
4+y=7
y=3

Therefore: (4,3)

3.2.1 Solving Linear Equations Using a Table

Choose values of x and calculate the corresponding values of y.

Equation:

y = 2x + 1
x y = 2x + 1
0 1
1 3
2 5
3 7
⚡ Pick easy x-values such as −2, −1, 0, 1, 2.

3.2.2 Substitution Method

Steps

  1. Make one variable the subject.
  2. Substitute into the other equation.
  3. Solve for one variable.
  4. Substitute back to find the other variable.
  5. Check the answer.
Solve:

x + y = 10
x − y = 2

From first equation:
x = 10 − y

Substitute into second:
10 − y − y = 2
10 − 2y = 2
−2y = −8
y = 4

x = 10 − 4 = 6

Answer: (6,4)
⚡ Choose the equation where a variable already has coefficient 1.

3.2.3 Elimination Method

The goal is to eliminate one variable by adding or subtracting the equations.

Solve:

2x + y = 9
3x − y = 11

Add:
5x = 20
x = 4

Substitute:
2(4)+y=9
8+y=9
y=1

Answer: (4,1)
⚡ Opposite coefficients → ADD.
Same coefficients → SUBTRACT.

3.2.4 Graphical Method

Each linear equation represents a straight line. The solution of two equations is the point where the two lines intersect.

Example:

y = x + 1
y = −x + 5

At intersection:
x + 1 = −x + 5
2x = 4
x = 2
y = 3

Solution = (2,3)

Types of Solutions

One solution: lines intersect once.

No solution: parallel lines.

Infinitely many solutions: same line.
🎯 Graph Trick:

Intersection point = solution.

3.3 Solving Non-Linear Equations

A nonlinear equation has a variable with power greater than 1 or another nonlinear form.

Examples:

x² + 3x − 4 = 0
x³ − 8 = 0
√x = 4
2ˣ = 16

3.3.1 Equations Involving Absolute Value

Meaning of Absolute Value

Absolute value represents distance from zero. Therefore it is always non-negative.

|x| ≥ 0
|5| = 5
|−5| = 5
|0| = 0

Basic Rule

|x| = a
x = a or x = −a

This rule applies when a ≥ 0.

Solve:

|x| = 7

x = 7
or
x = −7

Answer: x = ±7

Example with expression

Solve:

|2x − 3| = 5

Case 1:
2x − 3 = 5
2x = 8
x = 4

Case 2:
2x − 3 = −5
2x = −2
x = −1

Answer: x = 4 or x = −1
⚠️ Never write only x = a. For |x| = a, remember both +a and −a.
⚡ Absolute value = distance → distance cannot be negative.

3.3.2 Quadratic Equation

Definition

A quadratic equation is an equation whose highest power of the variable is 2.

ax² + bx + c = 0
a ≠ 0
Examples:

x² + 5x + 6 = 0
2x² − 7x + 3 = 0

3.3.2.1 Solving Quadratic Equations by Factorization

Solve:

x² + 5x + 6 = 0

Find two numbers whose:
Product = 6
Sum = 5

Numbers are 2 and 3.

Therefore:
(x+2)(x+3)=0

x+2=0 → x=−2
x+3=0 → x=−3

Answer: x = −2, −3
⚡ For x²+bx+c:

Find two numbers that multiply to c and add to b.

3.3.2.2 Completing the Square

Completing the square changes a quadratic expression into a perfect square.

x² + bx = (x + b/2)² − (b/2)²
Solve:

x² + 6x + 5 = 0

Move constant:
x² + 6x = −5

Half of 6 = 3
Add 9 to both sides:
x² + 6x + 9 = 4

(x+3)² = 4
x+3 = ±2
x = −3 ± 2

x = −1 or −5
⚡ Take half of the x-coefficient, then square it.

3.3.2.3 Quadratic Formula

x = [-b ± √(b² − 4ac)] / 2a

For:
ax² + bx + c = 0

Solve:

x² − 5x + 6 = 0

a=1, b=−5, c=6

x = [5 ± √(25−24)] / 2

x = [5 ± 1] / 2

x=3 or x=2
🎯 Always identify a, b, c before using the formula.

3.3.2.4 Discriminant

D = b² − 4ac

The discriminant tells us the nature and number of roots.

Discriminant Roots
D > 0 Two distinct real roots
D = 0 One repeated real root
D < 0 No real roots
For:
x² − 4x + 4 = 0

D = (−4)² − 4(1)(4)
D = 16 − 16
D = 0

Therefore there is one repeated real root.
⚡ Remember: + = 2 roots, 0 = repeated root, − = no real root.

3.3.2.5 Relationship Between Roots and Coefficients

For:

ax² + bx + c = 0

If the roots are α and β:

α + β = −b/a

αβ = c/a
For:
2x² − 7x + 3 = 0

a=2, b=−7, c=3

Sum of roots:
α+β = −(−7)/2 = 7/2

Product:
αβ = 3/2
⚡ Sum → −b/a
⚡ Product → c/a

3.3.3 Equations Involving Exponents

An exponential equation contains the variable in the exponent.

Solve:

2ˣ = 16

Write 16 as a power of 2:
16 = 2⁴

Therefore:
2ˣ = 2⁴
x = 4

Same Base Rule

aˣ = aʸ → x = y
when a > 0 and a ≠ 1

Example

Solve:

3ˣ⁺¹ = 27

27 = 3³
3ˣ⁺¹ = 3³
x+1=3
x=2
⚡ Convert both sides to the same base before comparing exponents.

⭐ Important Laws of Exponents

aᵐ × aⁿ = aᵐ⁺ⁿ

aᵐ ÷ aⁿ = aᵐ⁻ⁿ

(aᵐ)ⁿ = aᵐⁿ

a⁰ = 1

a⁻ⁿ = 1/aⁿ

aᵐ/n = ⁿ√(aᵐ)
2³ × 2²
= 2⁵
= 32
⚡ Same base × → ADD powers.
⚡ Same base ÷ → SUBTRACT powers.
⚡ Power of power → MULTIPLY powers.

3.3.3 Equations Involving Radicals

A radical equation contains a variable inside a root.

Solve:

√x = 5

Square both sides:
x = 25

Example 2

Solve:

√(x+1) = 4

Square both sides:
x+1=16
x=15

Example 3

Solve:

√(2x+3)=7

Square:
2x+3=49
2x=46
x=23
⚠️ Squaring can sometimes create an extraneous solution. Always substitute the answer back into the original equation.
⚡ Radical alone → isolate it first → square both sides → solve → CHECK.

⭐ Operations with Radicals

Adding and Subtracting

Only like radicals can be added or subtracted.

2√3 + 5√3
= 7√3
❌ √2 + √3 cannot be simplified to √5.

Multiplication

√a × √b = √(ab)
√3 × √12
= √36
= 6

Division

√a / √b = √(a/b)
√18 / √2
= √9
= 3

⭐ Rationalization

Rationalization means removing a radical from the denominator.

1/√2

Multiply numerator and denominator by √2:

= √2 / 2

Conjugate Method

1/(√3+1)

Multiply by:
(√3−1)

= (√3−1)/(3−1)
= (√3−1)/2
⚡ For a denominator containing √a + b, multiply by its conjugate √a − b.

⭐ Standard Form / Scientific Notation

Very large or very small numbers can be written as:

a × 10ⁿ
where 1 ≤ |a| < 10
450000
= 4.5 × 10⁵

0.00032
= 3.2 × 10⁻⁴
⚡ Decimal moves left → positive exponent.
⚡ Decimal moves right → negative exponent.

🔥 Entrance Exam Quick Tricks

1. Linear equation → isolate the variable.

2. Simultaneous equations → substitution or elimination.

3. Graphical solution → intersection point.

4. |x| = a → x = ±a.

5. Quadratic → ax²+bx+c=0.

6. Factorization → product c, sum b.

7. Quadratic formula → −b ± √(b²−4ac) / 2a.

8. Discriminant → b²−4ac.

9. Sum of roots → −b/a.

10. Product of roots → c/a.

11. Same exponential base → compare powers.

12. Radical equation → isolate → square → check.

13. √a × √b = √ab.

14. Rationalization → multiply by the conjugate.

⚠️ Common Exam Mistakes

❌ Forgetting to change the sign when moving terms.

❌ Using the quadratic formula with the wrong value of b.

❌ Forgetting ± when solving a squared equation.

❌ Forgetting to check radical-equation answers.

❌ Thinking √a + √b = √(a+b).

❌ Confusing sum of roots with product of roots.

❌ Forgetting that a proper quadratic equation requires a ≠ 0.
