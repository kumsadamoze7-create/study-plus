3.1 Revision: Linear Equation in One Variable

Definition

A linear equation in one variable is an equation whose highest power of the variable is 1.

ax + b = 0,   a ≠ 0

Example 1

Solve:

2x + 6 = 14

2x = 14 − 6
2x = 8
x = 4

Example 2

3(x − 2) = 15

3x − 6 = 15
3x = 21
x = 7
⚡ Short Trick:

Whatever you do to one side of an equation, do the same to the other side.
⚠️ Always check your answer by substituting it back into the original equation.

3.2 System of Linear Equations in Two Variables

A system of linear equations contains two or more equations involving the same variables.

ax + by = c

dx + ey = f

Example

x + y = 7
x − y = 1

Adding the equations:
2x = 8
x = 4

Substitute:
4 + y = 7
y = 3

Therefore:
(x,y) = (4,3)

A table can be used to find values of x and y that satisfy an equation.

3.2.2 Substitution Method

In substitution, solve one equation for one variable and substitute the result into the other equation.

Example

x + y = 10
x = 6

Substitute x = 6:
6 + y = 10
y = 4

Answer:
(x,y) = (6,4)

More Complex Example

y = 2x + 1
x + y = 10

Substitute:
x + (2x + 1) = 10
3x + 1 = 10
3x = 9
x = 3

y = 2(3)+1
y = 7
⚡ If one equation already has x = ... or y = ..., substitution is usually the fastest method.

3.2.3 Elimination Method

Elimination removes one variable by adding or subtracting equations.

Example

2x + y = 7
3x − y = 8

Add:
5x = 15
x = 3

Substitute:
2(3)+y=7
6+y=7
y=1
🎯 Shortcut: Look for opposite coefficients such as +y and −y.

When Coefficients Are Not Opposite

2x + 3y = 12
4x + 3y = 18

Subtract the first equation from the second:
2x = 6
x = 3

2(3)+3y=12
6+3y=12
y=2

3.2.4 Graphical Method

A system of two linear equations can be represented by two straight lines.

The solution is the point where the two lines intersect.

📌 Important:

One intersection → one solution
Parallel lines → no solution
Same line → infinitely many solutions

Example

y = x + 1
y = −x + 5

At the intersection:

x + 1 = −x + 5
2x = 4
x = 2
y = 3

Intersection = (2,3)
⚡ Graph question? Find the intersection point.

3.3.1 Equations Involving Absolute Value

Meaning of Absolute Value

Absolute value represents distance from zero.

|x| ≥ 0

|5| = 5
|-5| = 5

Basic Rule

|x| = a

x = a   or   x = −a

Example

|x| = 7

Therefore:
x = 7
or
x = −7

Example 2

|2x − 3| = 5

2x − 3 = 5
2x = 8
x = 4

OR

2x − 3 = −5
2x = −2
x = −1

x = 4 or x = −1
🎯 When |expression| = positive number, make TWO equations: + value and − value.
⚠️ |x| can never be negative. Therefore |x| = −3 has no real solution.

3.3.2 Quadratic Equation

A quadratic equation is an equation whose highest power is 2.

ax² + bx + c = 0

a ≠ 0

Examples

x² + 5x + 6 = 0
