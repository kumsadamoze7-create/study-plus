3.1 Revision on Linear Equation in One Variable

Definition

A linear equation in one variable is an equation in which the highest power of the variable is 1.

ax + b = 0,   a ≠ 0

Example

2x + 6 = 14

2x = 8
x = 4

Another Example

3(x - 2) = 15

3x - 6 = 15
3x = 21
x = 7
⚡ Short Trick: Move constants to one side and variables to the other. Remember: when a term crosses the equal sign, its sign changes.
⚠️ Always check your answer by substituting it back into the original equation.

3.2 System of Linear Equations in Two Variables

A system of linear equations contains two or more equations involving the same variables.

a₁x + b₁y = c₁
a₂x + b₂y = c₂

Example

x + y = 7
x - y = 1

Adding:
2x = 8
x = 4

Substitute:
4 + y = 7
y = 3

Answer: (x,y) = (4,3)

Solving Linear Equations Using a Table

Make a table of values for each equation and find the point where both equations have the same x and y values.

For:

y = x + 1
y = 5 - x

Try x = 2:
First equation: y = 2 + 1 = 3
Second equation: y = 5 - 2 = 3

Therefore: (2,3) is the solution.
⚡ Exam Trick: The common ordered pair is the solution of both equations.

Solving by Substitution Method

Steps

  1. Make one variable the subject.
  2. Substitute it into the other equation.
  3. Solve for one variable.
  4. Substitute back.
x + y = 9
x = 3

Substitute x = 3:
3 + y = 9
y = 6

Answer: (3,6)
⚡ Choose the equation where a variable is already isolated.

Solving by Elimination Method

Add or subtract the equations so that one variable disappears.

2x + y = 9
2x - y = 3

Add:
4x = 12
x = 3

Substitute:
2(3) + y = 9
y = 3

Answer: (3,3)
⚡ If coefficients are opposites, add the equations. If coefficients are equal, subtract them.

Solving by Graphical Method

The solution of two linear equations is the point where their graphs intersect.

For:
y = x + 1
y = -x + 5

Set equal:
x + 1 = -x + 5
2x = 4
x = 2
y = 3

Intersection = (2,3)
One intersection: one solution.

Parallel lines: no solution.

Same line: infinitely many solutions.

3.3.1 Equations Involving Absolute Value

Absolute value represents distance from zero, so it is always non-negative.

|x| = a

When a ≥ 0:

x = a   or   x = -a
|x| = 5

Therefore:
x = 5
or
x = -5

Example 2

|2x - 3| = 7

Case 1:
2x - 3 = 7
2x = 10
x = 5

Case 2:
2x - 3 = -7
2x = -4
x = -2

Answers: x = 5, -2
⚡ When you see |expression| = number, create TWO equations: positive and negative.
⚠️ If |x| = -3, there is NO real solution because absolute value cannot be negative.

3.3.2 Quadratic Equations

A quadratic equation is an equation whose highest power of x is 2.

ax² + bx + c = 0,   a ≠ 0
2x² + 5x + 2 = 0

Parts

a = coefficient of x²
b = coefficient of x
c = constant

Solving Quadratic Equations by Factorization

x² + 5x + 6 = 0

Find two numbers whose product is 6 and sum is 5:
2 and 3

Therefore:
(x + 2)(x + 3) = 0

x + 2 = 0 → x = -2
x + 3 = 0 → x = -3

Solutions: -2 and -3
⚡ Product = c, Sum = b.

Completing the Square Method

Convert the quadratic expression into a perfect square.

x² + bx + (b/2)² = (x + b/2)²
x² + 6x + 5 = 0

x² + 6x = -5

Add (6/2)² = 9:
x² + 6x + 9 = 4

(x + 3)² = 4

x + 3 = ±2
x = -3 ± 2

x = -1 or -5
⚡ Half the coefficient of x, then square it.

Quadratic Formula Method

x = (-b ± √(b² - 4ac)) / 2a
2x² + 3x - 2 = 0

a = 2
b = 3
c = -2

x = (-3 ± √(3² - 4(2)(-2))) / 4

x = (-3 ± √25) / 4

x = (-3 ± 5)/4

x = 1/2 or x = -2
⚡ Before using the formula, always identify a, b and c carefully.

Discriminant

The discriminant tells us the nature and number of roots of a quadratic equation.

Δ = b² - 4ac

Cases

Δ > 0
Two distinct real roots.

Δ = 0
One repeated real root.

Δ < 0
No real roots.
x² - 5x + 6 = 0

Δ = (-5)² - 4(1)(6)
= 25 - 24
= 1

Since Δ > 0, there are two distinct real roots.

Relationship Between Roots and Coefficients

For:

ax² + bx + c = 0

If the roots are α and β:

α + β = -b/a

αβ = c/a
For:
2x² - 7x + 3 = 0

a = 2
b = -7
c = 3

Sum of roots:
α + β = -(-7)/2 = 7/2

Product:
αβ = 3/2
⚡ Memory Trick:

Sum → negative b over a.
Product → c over a.

3.3.3 Equations Involving Exponents

An exponential equation contains the unknown in the exponent.

2ˣ = 16

Since:
16 = 2⁴

2ˣ = 2⁴
Therefore: x = 4

Example 2

3^(2x) = 27

27 = 3³
3^(2x) = 3³
2x = 3
x = 3/2
⚡ If both sides have the same base, equate their exponents.
⚠️ Make sure the bases are positive and equal before comparing exponents.

Important Laws of Exponents

aᵐ × aⁿ = aᵐ⁺ⁿ

aᵐ ÷ aⁿ = aᵐ⁻ⁿ

(aᵐ)ⁿ = aᵐⁿ

a⁰ = 1,   a ≠ 0

a⁻ⁿ = 1/aⁿ
2³ × 2²
= 2⁵
= 32

Equations Involving Radicals

A radical equation contains a variable inside a square root or another radical.

√x = 5

Square both sides:
x = 25

Answer: x = 25

Example 2

√(x + 4) = 6

Square both sides:
x + 4 = 36
x = 32
⚡ To remove a square root, square both sides.
⚠️ Always check the answer in the original radical equation. Squaring can sometimes introduce an extraneous solution.

More Difficult Radical Equation

√(2x + 3) = x

Square both sides:
2x + 3 = x²

Rearrange:
x² - 2x - 3 = 0

Factor:
(x - 3)(x + 1) = 0

x = 3 or x = -1

Check:
x = 3 → √9 = 3 ✅
x = -1 → √1 = -1 ❌

Answer: x = 3
🎯 Never accept radical-equation answers without checking them.

⭐ Unit 3 Entrance Exam Short Tricks

1. Linear equation:
Collect x terms and constants.

2. Substitution:
Make one variable alone first.

3. Elimination:
Make coefficients equal or opposite.

4. Graph:
Intersection = solution.

5. Absolute value:
|x| = a → x = ±a.

6. Quadratic:
ax² + bx + c = 0.

7. Factorization:
Product = c, Sum = b (when a = 1).

8. Quadratic formula:
Use when factorization is difficult.

9. Discriminant:
Δ > 0 → 2 roots
Δ = 0 → 1 repeated root
Δ < 0 → no real roots

10. Roots:
Sum = -b/a
Product = c/a

11. Exponents:
Same base → compare exponents.

12. Radicals:
Square both sides, then CHECK.

⚠️ Common Exam Mistakes

❌ Forgetting ± in square-root solutions.

❌ Using the wrong sign for b in the quadratic formula.

❌ Forgetting that a quadratic equation must be written as ax² + bx + c = 0.

❌ Forgetting to check radical-equation answers.

❌ Confusing subset-style symbols with equation symbols.

❌ Assuming every quadratic has two real roots.
